          Ajouter une matière

          Emploi du temps

          Coche les jours où tu as cours dans chaque matière. En créant un devoir pour un jour donné, l'application te propose les matières de ce jour-là, et la page « Aujourd'hui » affiche tes cours.

          Importer un emploi du tempsDepuis un fichier .csv, .txt, .ics (agenda) ou .json. Exemple : « Maths;lundi, mercredi » sur chaque ligne, ou un tableau avec une croix par jour.

          Notifications

          Rappel quotidienUne notification Windows avec les devoirs à rendre bientôt.
          Heure du rappelChaque jour à cette heure-là.
          Devoirs concernésJusqu'à quand regarder pour le rappel.
          Inclure les devoirs en retardIls sont ajoutés au rappel tant qu'ils ne sont pas terminés.
          Un rappel par devoirUne notification pour chaque devoir à rendre demain (la veille de l'échéance).
          Heure du rappel par devoirPar exemple la veille à 18h.
          Rappel du matinUne notification « tes devoirs du jour ».
          Heure du rappel du matinChaque jour à cette heure-là.
          Boutons dans la notification« Marquer fait » et « Rappeler demain » directement depuis la notification d'un devoir, sans ouvrir l'appli.
          Son de notificationChoisis un son, ou rends les notifications silencieuses.
          Mode vacancesCoupe tous les rappels entre deux dates.
          Début des vacancesPremier jour sans rappel.
          Fin des vacancesDernier jour sans rappel.
          Rester actif en arrière-planFermer la fenêtre garde l'application dans la zone de notification, pour que les rappels arrivent quand même. Clic droit sur son icône pour la quitter.
          Lancer au démarrage de WindowsL'application démarre discrètement dans la zone de notification.
          TesterEnvoie une notification pour vérifier que tout marche.

          Organisation

          Modèles de devoirs

          Un modèle remplit le formulaire en un clic (titre, durée, étapes…). Pour en créer un : « Enregistrer comme modèle » dans « Nouveau devoir ».

          Archiver automatiquementLes devoirs terminés depuis longtemps quittent la liste (ils restent dans les statistiques et dans « Archive »).
          ArchiveLes devoirs archivés.
          CorbeilleUn devoir supprimé reste récupérable pendant 30 jours.

          Confort

          Langue

          L'application se recharge pour changer de langue.

          Mini-widget
          Afficher le mini-widgetUne petite fenêtre toujours visible avec les devoirs en retard, d'aujourd'hui et de demain.
          L'ouvrir au démarrageLe widget s'affiche dès que l'application se lance.
          Code de verrouillage
          Code d'accèsAucun code. Demande un code pour ouvrir l'application.

          Verrouiller après inactivitéRedemande le code quand tu n'utilises plus l'application.

          Le code empêche d'ouvrir l'application (Ctrl+L pour la verrouiller tout de suite) et cache les devoirs dans le widget. Il ne chiffre pas le fichier de données, et les notifications peuvent montrer le titre des devoirs.

          Synchronisation entre ordinateurs

          Choisis un dossier partagé (OneDrive, Google Drive, clé USB…) sur chaque ordinateur : les devoirs, la corbeille, l'archive, les matières et les modèles sont fusionnés automatiquement. Retirer une matière n'est pas synchronisé.

          Dossier de synchronisationDésactivée.
