# Raccourcis clavier

| Raccourci | Action |
|---|---|
| `Ctrl` + `N` | Nouveau devoir |
| `Q` | Ajout rapide |
| `Ctrl` + `F` ou `/` | Rechercher |
| `Ctrl` + `I` | Statistiques |
| `Ctrl` + `P` | Imprimer ou enregistrer en PDF |
| `Ctrl` + `Maj` + `D` | Changer de thème |
| `Ctrl` + `L` | Verrouiller l'appli |
| `Ctrl` + `Z` | Annuler |
