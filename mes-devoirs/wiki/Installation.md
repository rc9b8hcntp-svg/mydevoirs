# Installation

Les installeurs se téléchargent depuis le [site](https://rc9b8hcntp-svg.github.io/mydevoirs/) ou depuis la [dernière version](https://github.com/rc9b8hcntp-svg/mydevoirs/releases/latest) sur GitHub.

## Windows

| Ordinateur | Fichier |
|---|---|
| x64 (64 bits) | `CartableOS-<version>-x64.msi` |
| x86 (32 bits) | `CartableOS-<version>-ia32.msi` |
| ARM64 | `CartableOS-<version>-arm64.msi` |

Chaque installeur installe Cartable OS **et** Mes Devoirs. Il crée un raccourci Cartable OS sur le Bureau et dans le menu Démarrer ; les raccourcis de Mes Devoirs sont créés par Cartable OS au premier lancement.

## Mac

| Ordinateur | Fichier |
|---|---|
| Apple Silicon (M1, M2, M3…) | installeur `.dmg` |
| Intel | installeur `.dmg` |

## Mises à jour

**Paramètres → Mise à jour** compare ta version avec la dernière version publiée sur GitHub. Quand une version est disponible, l'appli affiche ses nouveautés, puis le bouton **Télécharger et installer** :

1. choisit tout seul l'installeur adapté à ton ordinateur,
2. le télécharge avec une barre de progression et vérifie qu'il est complet (taille et empreinte SHA-256),
3. ouvre l'installeur, puis ferme Mes Devoirs pour que l'installation puisse remplacer ses fichiers.

Si aucun installeur ne correspond à ton ordinateur, ou si le téléchargement échoue, l'appli propose d'ouvrir la page de la version à la place.

Le menu « Version à rechercher » permet aussi de choisir une version précise pour revenir en arrière.
